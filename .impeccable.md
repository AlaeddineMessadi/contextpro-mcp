## Design Context

### Users
Developers operating ContextPro across local projects and coding-agent sessions. They need to see whether a project is ready, investigate tool activity, and inspect indexes, code relationships, memory, and resource usage.

### Brand Personality
Clear, capable, composed. The creator wants a useful, comprehensive dashboard that feels current and avoids overwhelming the user.

### Aesthetic Direction
A restrained developer console: warm light surfaces, ink typography, forest-green accents, a compact navigation rail, and generous space around the active task. Calm console direction is a working assumption following the creator's request to continue; no external visual references were supplied.

### Design Principles
1. Start with readiness and recent activity; reveal detail in dedicated views.
2. Preserve project and worktree context throughout every interaction.
3. Make loading, stale data, empty data, and failures visibly distinct.
4. Describe measured facts accurately; estimates are never billing savings.
5. Keep every view usable by keyboard and on a narrow screen.
