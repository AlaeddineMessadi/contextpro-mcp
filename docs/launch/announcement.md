## Primary message

**ContextPro: find the code, keep the context small.**

ContextPro is an MIT-licensed MCP server that gives coding agents bounded source context, TypeScript/JavaScript reference evidence and reusable project memory. It runs locally, starts with three tools in its lean profile, and exposes freshness, scope and fallback warnings so agents can decide what to verify next.

Connect it to Codex, Claude Code or OpenCode. Use structural reads without an embedding service, or add local or hosted embeddings for semantic retrieval.

We are looking for contributors who care about reference completeness, realistic benchmarks, language support and fast, useful agent workflows. Try it on a repository, share a small reproduction when something is missing, and help us improve the evidence an agent sees.
